# bgm-channel-ops

BGM・環境音YouTubeチャンネルの運用において、**新規・小規模チャンネルが競合から抜け出し、最短で成長するための「勝ち筋」や戦略・仮説検証を分析・整理・蓄積するプロジェクト**です。

---

## 🎯 プロジェクトの目的

YouTubeにおけるBGMジャンルは大手・老舗チャンネルによる囲い込みと、生成AI（Suno, Udio等）の普及による音楽BGMの過多・コモディティ化が進んでいます。

本プロジェクトでは、YouTube APIを活用したデータ分析ツール（[`youtube-research-toolkit`](https://github.com/ymkge/youtube-research-toolkit)）のモニタリングデータや実データに基づき、**小規模チャンネルが初速（数百〜数千再生）を獲得し、チャンネル登録者を最大化するための再現可能な構造と戦略**を分析・蓄積・実践します。

---

## 💡 小規模チャンネルの「勝ち筋」分析サマリー

### 1. 構造的背景：なぜ「音楽」ではなく「自然環境音」なのか？
* **AI音楽BGMの飽和**：クオリティの高いLofi/Piano BGMが大量に供給されており、大手がブランディングと登録者を囲い込んでいるため、新規参入で差別化が困難。
* **実用ノイズニーズの増大**：ユーザーが作業・勉強・睡眠時に求めているのは「メロディ」ではなく「脳の邪魔をしないホワイトノイズ/1/fゆらぎ」。
* **YouTubeアルゴリズムとの相性**：環境音は長時間のバックグラウンド再生が発生しやすく、総再生時間（Watch Time）の評価が上がりやすい。

---

### 2. 伸びを最大化する「3大黄金方程式」

$$\text{【初期の勝ちパターン】} = \text{【4大自然環境音】} \times \text{【ポモドーロ機能】} \times \text{【一目でわかる直感サムネイル】}$$

#### ① 4大自然環境音（メイン音源）
1. **川のせせらぎ**（集中・勉強・作業用）
2. **雨の音 / 雨音×ピアノ**（深い集中・落ち着き・睡眠）
3. **波の音 / 夜の海**（リラックス・ポモドーロ）
4. **焚き火の音**（夜作業・集中・ASMR）

#### ② ポモドーロ機能（タイマー枠）
* `25分集中 × 5分休憩`（1時間 / 2時間 / 4時間）の枠組みを明確に提供。

#### ③ 直感型サムネイル（極限の視認性）
* 「音の種類」と「時間枠」を画面中央〜上部に巨大太文字で明記。
* 例：`雨音×ピアノ 2時間` / `波の音 25:00` / `超集中できる音 川のせせらぎ`

---

### 3. 企画（文脈）の具体化：3要素の組み合わせ

単なる「勉強用BGM」ではなく、ターゲットが「自分向けだ」と感じる切り口を設計します。

1. **シチュエーション**（医療系資格勉強、在宅ワーク、朝4〜6時、夜のキャンプ）
2. **感情のゴール**（やる気ゼロから即集中、心の雑音をオフ、不安を鎮める）
3. **世界観・ノスタルジー**（平成レトロ商店街、昭和喫茶店、青の空間、雨の窓辺）

## ⚠️ 運用・リスク管理ガイドライン

* **YouTube「繰り返しの多いコンテンツ」対策**：
  単一の商用フリー音源ループ＋静止画は収益化無効化リスクがあります。複数の環境音（例：川の音 70% + 鳥の声 20% + 風音 10%）を独自にミックスし、映像に微かなアニメーションやストーリー性の音の変化を組み込みます。
* **著作権・商用利用**：
  音源・画像・フォントのライセンス範囲を厳重に管理します。

## ⚡ 初期48時間アルゴリズム攻略＆テスト通過基準

YouTubeのインプレッション拡大は、投稿直後の**「初期48時間テスト」**（インプレッションに対するCTR・連続視聴維持率・リピート率）をクリアすることで、関連動画やおすすめ（Home）への露出が中長期的に自動拡大する仕組みになっています。

* **CTR目標**：**8.0% 〜 12.0% 以上**（スマホ画面0.5秒で手が止まるデカ文字・高コントラストデザイン）
* **連続視聴維持率**：1セット目（25分）の完走率 **60%以上**（冒頭の期待一致と、脳を飽きさせない音の微変化）
* **リピート率**：**20% 以上**（チャンネル登録・他動画への回遊導線設計）

詳細な評価基準と運用設計は [`docs/youtube_initial_48h_framework.md`](file:///Users/ymto/Documents/git/bgm-channel-ops/docs/youtube_initial_48h_framework.md) に整理されています。

## 🤖 専門サブエージェント体制（企画制作＆ダブルチェック）

本リポジトリでは `.agents/` 内に定義された**専門サブエージェント体制**により、企画から動画構成、品質保証までを最高精度で実施します。

1. 🎨 **`youtube-content-creator`（企画・制作プロデューサー）**
   * スマホ最適化された巨大文字サムネイル選定、ターゲット悩みの言語化タイトル、AI画像生成プロンプト、動画の台本（ポモドーロ音源タイムライン・演出）を策定。
2. 🛡️ **`youtube-quality-checker`（ダブルチェック・品質チェッカー）**
   * 初期48時間テスト通過確率（推定CTR 8〜12%）、視聴維持率、YouTube「重複コンテンツ」ポリシー適合性を客観的に評価・スコアリングし、確度を高める修正指示を発行。
3. 🔍 **`strategy-reviewer`（戦略＆総合リスク評価）**
   * 企画全体・ドキュメントの権利関係・長期ブランディングリスクを検証。
