## 🎵 Phase 2: 音源ミックス仕様 (DaVinci Resolve / Fairlight)

- [ ] **トラック1: 1/fゆらぎ自然音 (70%)**
  - 9月の秋雨（屋根や窓ガラスを叩くしとしと雨音＋静かな雫音。※雷・強風は除外）
  - **1/fゆらぎ演出**: 10分目・20分目に雨足の強弱を微妙に変化させ、遠くの静かな雷/風音を1度忍ばせる。
- [ ] **トラック2: アンビエント / 静かなLo-Fi (30%)**
  - **集中パート (25分)**: 低音フェルトピアノ ＋ 柔らかなシンセパッド（メロディの主張なし）
  - **休憩パート (5分)**: 温かみのあるアコースティックギター / カリンバ（脳の緊張緩和）
