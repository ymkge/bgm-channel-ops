# 🖼️ サムネイル高CTR設計フレームワーク＆落とし穴回避ナレッジ
（YouTubeアルゴリズム・RAG参照用ナレッジベース）

本ドキュメントは、インプレッション拡大時（数千〜数万回）でもCTR 3.0%〜3.5%以上を維持し、インプレッションの急死（CTR 1%台への急落）を未然に防ぐための**「サムネイル設計の鉄則・禁則事項・落とし穴回避ルール」**を体系化したナレッジベースです。
今後のAIエージェントによるサムネイル・タイトル企画時の必須参照ルールとします。

---

## 1. 【最重要禁則】時間軸ワードの完全排除（時間帯フリーの鉄則）

### ❌ やってはいけないこと（落とし穴）
サムネイルの文字に**「夜」「朝」「深夜」「午後」「黄昏」などの時間帯を限定するワードを絶対に入れないこと。**

### 🔍 なぜ時間軸ワードがCTRを破壊するのか？
* **アルゴリズムのタイムラグのブレ**:
  YouTubeが動画を認識してインプレッションを本格配分するタイミングは、サーバーの混雑や競合により**4時間〜12時間平気でズレる**（例: 夕方17:30に公開した夜向け動画が、翌朝4:30〜8:00に垂直放出される）。
* **朝・昼のユーザーの認知的不一致（システム1による即スキップ）**:
  朝や昼間にスマホを開いたユーザーは「朝活・覚醒モード」にあるため、サムネイルに「夜」「月夜」と書いてあると、0.1秒で**「これは夜見る動画だ（今は朝だから違う）」と無意識にスルー**する。
* **結果**: 朝・昼に配られた数千回のインプレッションでCTRが1.0%に急落し、AIが「低需要動画」と誤認して露出を即座に停止させる。

### ⭕️ 正しい設計ルール
* **サムネイルは「24時間いつでもクリックできる普遍的な言葉」に統一する。**
* 背景画像が夜景・満月であっても、文字で「夜」と断定しなければ、昼間に見たリスナーも「薄暗い落ち着いた和モダンカフェ」「高級ホテルのラウンジ」と脳内で好意的に解釈し、CTRが落ちない。

| ❌ 失敗例（時間帯で死ぬサムネ） | ⭕️ 成功例（24時間クリックされるサムネ） |
| :--- | :--- |
| `誰にも邪魔されない夜` | **`誰にも邪魔されず集中`** |
| `深夜に一瞬で無心になる` | **`気がつけば集中`** |
| `秋の夜長と川の音` | **`川の音×ピアノ 作業用BGM`** |

## 2. 文字数の極小化・デカ文字ルール（7〜10文字の黄金比）

スマホ一覧画面や、関連動画枠（Suggested videos: 全体の65〜80%を占める主戦場）では、**サムネイルが幅数センチの極小サイズで表示**される。

### ① 1行目（メインコピー）：【7〜10文字以内】
* **文字数の掟**: 最大でも10文字、できれば**7〜8文字**が最もCTRが高い。
* **フォントサイズ**: スマホ縮小時でも0.1秒で読めるよう、画面の横幅いっぱいに極太デカ文字で配置。
* **文字の視覚的輪郭（漢字とひらがなのサンドイッチ構造）**:
  * 最初と最後を角ばった「漢字」で挟むと、視覚的ブロック（四角い塊）として輪郭がクッキリ立ち、スクロールを物理的に止める。
  * 例: `気がつけば集中`（【漢字：気】＋【ひらがな：がつければ】＋【漢字：集中】）

### ② 2行目（サブコピー）：【14〜16文字以内】
* **余計な修飾語の徹底排除（引き算の美学）**:
  * ❌ `川のせせらぎ×月光ピアノ 作業用BGM`（19文字：長すぎて文字が小さくなる）
  * ⭕️ `川の音×ピアノ 作業用BGM`（14文字：文字サイズを最大化できる）
* **画像の視覚情報と重複させない**:
  * 画像にすでに「満月」が大きく映っているなら、文字でわざわざ「月光」と書く必要はない（画像が語っているため）。
  * 「画像の視覚」と「文字の音響情報」を完全に役割分担させる。

## 3. 「抽象的・哲学的ワード」の禁止と「具体的ベネフィット」の徹底

### ❌ CTRが急落するNGワード（手垢のついた抽象語・硬い言葉）
* `超集中` `ひたすら集中` `徹底集中` ➔ 単なる道具の説明で、脳が論理的に比較してスルー。
* `無の境地` `一瞬で無心になる` ➔ 瞑想的・スピリチュアルで、作業を進めたい大衆にとってクリック動機が弱い。
* `没頭` ➔ 文章語として硬く、中高生や疲れたライト層に敷居の高さを感じさせる。
* `夢中` ➔ 勉強・作業であることが伝わりにくく、ゲームや趣味と誤認されやすい。

### ⭕️ 誰でも親しみやすく、つい押したくなるキラーワード
* **`誰にも邪魔されず集中`**（10文字）: 「スマホの通知・周囲の割り込みの排除」という全人類のペインを直撃。
* **`気がつけば集中`**（7文字）: 「頑張らなくても、自然と集中できる」というハードル破壊（過去動画で総再生89.5hの実績あり）。
* **`勝手に手が動き出す`**（8文字）: やる気が出ないときの先延ばしを打破する最強の体験価値。

## 4. デザイン工学：カラーシンクロ ＆ 一人称視点（POV）

1. **カラーシンクロ（背景色と強調色の連動）**:
   * 文字の強調色は、浮いた蛍光色を使わず、**「背景イラストのキーカラー」から抽出する**。
   * 例: 紅葉背景 ➔ 鮮烈なオレンジ / 満月背景 ➔ 月光ゴールド（琥珀色）
   * これにより「広告臭（安っぽさ）」が消え、上質なアート作品として瞬時に受容される。
2. **2色ルール（白 ＋ アクセント1色）**:
   * ベースは白文字（黒シャドウ・座布団付き）。
   * 最も強調したい2〜3文字（例: 「集中」「手が動き出す」）のみをアクセントカラーで発光させる。
3. **一人称視点（POV）構図の厳守**:
   * 手前に木製デスク、開いたノート、ペン、カップを配置。
   * 「他人が作業する様子を見る」のではなく、**「リスナー自身がその席に着席する主観視点」**を提供することでタップへの抵抗をゼロにする。

## 5. 動画公開タイミングの運用原則

アルゴリズムのインプレッション配分にブレがあるからといって、公開時刻をランダムにしてはならない。
**「公開直後にリアルタイムで動画をクリックしてくれるアクティブユーザーがいる時間枠」**に固定する。

* **朝枠（朝活・勉強・爽やか系）**: 【早朝 5:00 〜 7:00】に公開
  * 早起き層・朝活層が即座に反応 ➔ 7:00〜9:00の通勤・朝学習ピークに拡大。
* **夜枠（落ち着き・満月・夕暮れ系）**: 【夕方 17:00 〜 18:00】に公開
  * 帰宅・夕食時に助走インデックス ➔ 19:30〜23:00の夜活ピークに拡大。

## 6. チャンネル別 適用マトリクス（普遍的ルール vs ポモスタ独自 vs 海外新チャンネル）

本ドキュメントのナレッジは、**「世界共通・アルゴリズム普遍のルール」**と、**「チャンネルのターゲット・文化特性によって変わるルール」**に明確に分類されます。今後の新チャンネル展開時に混同しないよう以下に定義します。

| 設計項目 | 🌐 全チャンネル共通（普遍的ルール） | 🇯🇵 ポモスタ（国内向け・ポモドーロ） | 🌍 海外向け新チャンネル（Quiet Luxury / Deep Work） |
| :--- | :--- | :--- | :--- |
| **① 時間軸ワードの排除** | **【完全共通・最重要】**<br>いつ露出されても死なない「時間帯フリー」の徹底。 | **【厳守】**<br>「夜」「朝」を文字に入れず、24時間クリック可能な言葉にする。 | **【さらに重要度UP】**<br>世界中で時差（US/EU/アジア）があるため、時間限定の言葉は致命傷になる。 |
