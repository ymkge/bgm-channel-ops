# 🧠 01. YouTubeヒットとバズのコア原則 ＆ システム前提知識

本ドキュメントは、AIエージェントがYouTube動画の「タイトル」「サムネイル」「動画構成」を生成・企画する際に、常に最優先で参照すべき**絶対的な設計原則**を定義します。

---

## 1. 人間心理：視聴者は「欲望の解消」を買っている
- **原則**: 視聴者は動画そのもの（音楽や映像という手段）を求めているのではなく、**「その動画を観た結果、自分の嫌な感情や悩みが解消された理想の未来（欲望）」**を求めてアクセスする。
- **ターゲットのCore欲望パターン**:
  - `勉強・学習層`: 「億劫でやりたくない勉強が、気付いたらあっという間に終わっている楽さを得たい」「サボる罪悪感を消して自尊心を得たい」
  - `作業・社会人層`: 「重い腰を上げて一気に仕事を終わらせ、自由になりたい」「脳を疲させずにゾーンに入って快適に没頭したい」
  - `リラックス・睡眠層`: 「考えごとやストレスを消し、一瞬で深く眠って体調を整えたい」

## 2. アルゴリズム構造：バズを起こす二大歯車
YouTube の推薦アルゴリズム（おすすめ表示 / 関連動画）は、以下の2段階審査で配給インプレッションを決定する。

```text
【ステップ1：入口 (CTR)】
サムネイル ＋ タイトルで「欲望解消の約束」を提示する
 ➔ 画面上の視線を止め、クリック率 (CTR 4.0% 〜 8.0% 以上) を獲得する
     ↓ (※合格した場合のみ、次の配給枠へ昇格)
【ステップ2：中身 (平均視聴維持時間)】
動画本編で「本当に欲望が解消された体験」を提供する
 ➔ 平均視聴時間 20〜30分以上 (ポモドーロ/長尺BGMの場合) を達成する
     ↓
【結果：爆発的インプレッション配給 (バズ)】
YouTube が数万〜数十万回の配給制限を全開解除する
```

## 3. タイトル＆サムネイル設計の黄金配置ルール

### A. タイトル先頭の原則
- **1文字目〜15文字目**: 必ず人口が極大の**巨大ビッグワード（`【勉強用BGM】`, `【作業用BGM】`, `【カフェBGM】` 等）**を置くこと。（インプレッションの母数を最大化するため）
- **中央部**: `[感情・悩みの解消フック]` + `[仕様/音の種類]` を置く。
- **末尾**: 視聴者の心を掴む **`『[背中を押す強い名言 / マインドセット]』`** を置く。（チャンネル登録転換率を最大化するため）

### B. サムネイルの原則
- 単なるジャンル名（例: 「ピアノBGM」）ではなく、**「直球の欲望解決フレーズ（例: `気がつけば作業終了`, `やる気ゼロでも即没頭`）」**を最も太く目立つ色で文字配置すること。
- タイトルの感情フックとサムネイル文字を 100% 同期させること。
