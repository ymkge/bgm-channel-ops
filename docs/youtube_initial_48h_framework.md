# YouTube初期48時間アルゴリズム攻略＆中長期インプレッション拡大フレームワーク

本ドキュメントは、YouTubeに動画を投稿した直後の**「初期48時間テスト」**を突破し、アルゴリズムによってインプレッション（おすすめ・関連動画表示）を中長期的に自動拡大させ続けるための完全攻略ガイドです。

---

## 1. YouTube「初期48時間テスト」のメカニズム

YouTubeのインプレッション拡大は、段階的なテスト配信によって決定されます。

```text
[動画投稿] 
   │
   ▼
【フェーズ1：初期48時間テスト】
  ├ 登録者・チャンネル類似層へインプレッション配給（数千〜数万インプレッション）
  ├ 判定指標：CTR（クリック率） × 平均視聴時間（Watch Time） × リピート率
   │
   ├─ (テスト合格) ──► 【フェーズ2：関連動画・ブラウジング拡大】（類似視聴者へ爆発的拡散）
   └─ (テスト不合格) ─► 【拡散停止】（検索流入のみの低空飛行）
```

### 初期48時間でクリアすべき合格基準（ベンチマーク目標）

| 指標 | 初期48時間の合格目標 | 理由・狙い |
|---|---|---|
| **CTR（クリック率）** | **8.0% 〜 12.0% 以上** | 検索・おすすめ画面で「他動画を押し退けてクリックされる」強さ |
| **平均視聴維持率** | **50% 以上（2時間動画の場合20分〜30分以上連続視聴）** | 「途中で離脱されず、セッション時間を伸ばしている」評価 |
| **セッション完走率** | 1セット目（25分）完走率 **60%以上** | タイマーとしての実用性とストレスのない音質・構成 |
| **リピート視聴率** | **20% 以上** | 投稿後48時間以内に同ユーザーがチャンネルの他動画や再視聴を行う率 |

---

## 2. 三大指標（CTR・連続視聴時間・リピート率）最大化の具体的設計

### ① CTR（インプレッション数×クリック率）最大化の法則
スマホ画面で「0.5秒」で判断される視認性とスクロールストップ（手を止めさせる）設計。

* **サムネイル視認性法則**：
  * **デカ文字（画面の30%以上）**：`雨音×ピアノ 2時間` / `波の音 25:00` / `超集中 川のせせらぎ`
  * **タイマー数字の強調**：`2時間` `60分` `25分×4` など時間を数字でデカデカと提示
  * **配色コントラスト**：暗い背景（夜・海・雨・デスク）× 発光感のある白/黄/シアン文字
* **タイトル補律法則**：
  * サムネイルで書いた言葉を補強し、**「悩み・ターゲット」**を追加。
  * 例：`【ポモドーロ 2時間】やる気ゼロからゾーンに入る「小川のせせらぎ」｜25分集中+5分休憩 ×4セット 作業用BGM`

### ② 連続視聴時間（Watch Time / Session Duration）最大化の法則
動画を開いたあとに**「2時間流しっぱなし」**にさせる構成（フック＆環境設計）。

* **最初の5秒の約束**：動画開始0秒でサムネイル通りの音とタイマー画面（カウントダウン）を表示し、「騙された」感をゼロにする。
* **音の構成（1/fゆらぎ×微変化）**：
  * 単なる10分ループではなく、25分の中で「微かな音の変化（雨足が強まる・風が吹き抜ける）」を入れ、脳の飽きを防止。
  * 25分後の**「5分間休憩」に心地よいリフレッシュ音（ピーンという澄んだ鈴音＋鳥の声やカフェ音）**を配置し、作業のメリハリを作る。

### ③ リピート率（チャンネル登録・再訪問）最大化の法則
動画を単なる「一発もの」から「毎日の習慣（インフラ）」へ変える設計。

* **ブランドの一貫性（サムネイル・音質）**：同チャンネルの動画であることが一目で分かる統一デザイン。
* **チャンネル概要欄・終了画面の導線**：
  * 「明日の作業用：【朝活版】朝露の湖ポモドーロ」へのリンク配置。
  * プレイリスト化（「2時間ポモドーロシリーズ」「雨音シリーズ」）。

## 3. 初期48時間突破のためのPDCA運用フロー

```text
[企画・素材作成]
   │
   ▼
[youtube-content-creator による作成]
   ├ サムネイル、タイトル、イラスト選定、台本・構成の作成
   │
   ▼
[youtube-quality-checker による検証]
   ├ 初期48時間テスト通過確率、CTR最大化、重複コンテンツ回避のチェック
   │
   ▼
[投稿・初期48時間モニタリング] (`youtube-research-toolkit` 連動)
   ├ CTRが8%未満 ──► サムネイル・タイトルを即時差し替え（テストのやり直し）
   └ CTR 8%以上 ──► アルゴリズム乗波を確認
```
