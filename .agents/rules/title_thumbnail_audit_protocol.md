# 🎯 ポモスタ専用：タイトル＆サムネイル常時監査プロトコル (KPI: 100K Imp / 5% CTR / 30m AVD)

本規約は、YouTubeチャンネル「ポモスタ」における動画の心臓部である「サムネイルコピー」および「タイトル」を策定・提案する際、**例外なく常にサブエージェントによるアルゴリズム＆心理学監査を実行する**ための運用プロトコルである。

---

## 1. 監査の絶対KPI体系（優先順位）

すべてのタイトル・サムネイル案は、以下の3大KPIを達成できるかを数理モデル・実測データに基づいてシミュレーションし、**「確信度（%）」**を付与して評価・判定しなければならない。

$$\text{優先順位: } \mathbf{① \text{ インプレッション 10万回以上}} > \mathbf{② \text{ CTR 5.0\% 以上}} > \mathbf{③ \text{ 連続視聴時間（AVD） 30分以上}}$$

| KPI項目 | 目標基準 | 監査・判定の検証ポイント |
| :--- | :---: | :--- |
| **① インプレッション** | **10万回以上** | **【マス層（数千万人）への適応性 ＆ 大衆直感性テスト】**<br>・**大衆直感性テスト合格必須**: 「深く潜る」「静寂に沈む」「思考を溶かす」などのディープワーク文学的比喩表現を完全排除し、中学生でも0.05秒で直感理解できる直球日常語（一気に集中、頭が冴える、片付く等）になっているか？<br>・特定ニッチ層を優遇するあまり、大衆（80%）を門前払いするフィルター（認知的拒絶）がないか？<br>・ブラウジング機能（ホーム画面）で広く拡散され続けても希釈化されない普遍的欲望か？<br>・タイトルに「勉強用」「作業用BGM」を併記し、関連動画の推薦経路を最大化しているか？ |
| **② CTR（クリック率）** | **5.0% 以上** | **【初動0.2秒の衝動性 ＆ 純度100%二重トラップ】**<br>・**同語反復・オウム返しの完全排除**: サムネイル文言（例:「作業の手が止まらない」「ゾーンに入る」）が、タイトル先頭や本文で1単語でも重複・オウム返しされていないか？サムネとタイトルは100%別角度から挟み撃ちにする「二重トラップ」になっているか？<br>・直近4回のクールダウン台帳（バナーブラインドネス・末尾着地被り防止）を厳守しているか？<br>・禁忌NGワード（没入・没頭・遮断・ポエム・能動態プレッシャー）が1文字も混入していないか？ |
| **③ 連続視聴時間** | **30分 以上**<br>*(1セット完走)* | **【期待値一致 ＆ 聴覚的居心地の良さ】**<br>・サムネイルで掲げた「音（雨音・自然音など）」や「世界観」と動画内容が100%合致しているか（クリックベイトによる早期離脱の防止）？<br>・言語野フリー（無関連音声効果の防止）および1/fゆらぎ音響により、作業中に聴覚疲労を起こさない設計か？ |

## 2. 常時監査の実行ワークフロー

1. **メインエージェントがタイトル・サムネ案を策定**:
   * 最低3パターン（初期本命案、差し替え案①、差し替え案②）を考案。
2. **サブエージェント（`Senior YouTube Growth Strategist`）の自動召集**:
   * **17大敗因チェックリスト（`low_ctr_failed_cases_database.md`）の100%照合**:
     - 【最重要チェック1】サムネとタイトルの文言被り（同語反復・部分一致）の完全ゼロ確認。
     - 【最重要チェック2】大衆直感性テスト（比喩・ポエム『潜る』等の完全排除、中学生でも0.05秒で直感理解できる直球語のみ採用）。
     - 【最重要チェック3】同一背景シリーズにおける末尾着地ワード（「集中」等）の連続被り防止。
   * **実績データCSVの参照**: `data/youtube_analytics_history.csv` を直接読み込み、直近4〜5本の動画タイトル・サムネの重複を完全検証する。
   * **ナレッジドキュメントとの照合**: `low_ctr_failed_cases_database.md`, `thumbnail_killer_words_database.md`, `hit_vs_nomusic_ctr_gap_analysis.md` と照合。
   * **概要欄（Description）日本語品質・自然性監査**:
     - 専門用語・学術用語の完全排除（例: 「言語野」「ワーキングメモリ」「認知負荷」「音韻ループ」「phonological loop」等を使用せず、「読む・書く・考える力」「思考の邪魔ゼロ」「脳のエネルギー」などの平易な日常語に置き換えているか）。
     - 文脈の自然さ・接続の滑らかさ（例: 「雑音ゼロの静寂の中で集中」のような単語の無理な詰め込みを排除し、「周囲の雑音をゼロにして静寂の中で集中」のように、主語・動詞・修飾が自然に繋がっているか）。
     - 小学生でも0.1秒で情景が浮かび、状況をリアルに想像できる自然な日本語になっているか。
   * 3大KPI（10万インプ ＞ CTR 5% ＞ AVD 30分）の達成シミュレーションを実行。
3. **確信度（%）と根拠の提示**:
   * 各案に客観的な確信度（%）を付与し、リスクや改善点を明記した上でユーザーへ提示する。

## 3. 概要欄（Description）作成の絶対レギュレーション

今後のすべての動画概要欄（日英）において、以下の執筆基準を固定ルールとして適用する。

1. **専門用語の平易化マッピング**:
   - `言語野 / ワーキングメモリ` ➔ `読む・書く・考える力` / `思考スペース` / `脳のエネルギー`
   - `認知負荷 / 認知的フリクション` ➔ `思考の邪魔` / `余計なストレス`
   - `phonological loop (英)` ➔ `mental distraction` / `free your mind`
2. **自然な動詞・助詞の接続（状況想起の保証）**:
   - 単語を強引に圧縮したコピー調（体言止めの連続）を避け、視聴者が「自分がその空間で作業している姿」をスムーズに想像できる丁寧で流暢な日本語にする。
   - 冒頭注記の標準形:
     `※本動画はピアノ・楽器を一切使用しない【完全自然音（音楽なし）】仕様です。周囲の雑音をゼロにして静寂の中で集中したい時にご活用ください☕`
3. **完全日英分離**:
   - 日本語ブロックと英語ブロックを完全に分離し、それぞれの言語文化において最も自然で品格のある文体（Quiet Luxury）を維持する。
