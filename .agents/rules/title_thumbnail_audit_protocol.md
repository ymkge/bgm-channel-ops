# 🎯 ポモスタ専用：タイトル＆サムネイル常時監査プロトコル (KPI: 100K Imp / 5% CTR / 30m AVD)

本規約は、YouTubeチャンネル「ポモスタ」における動画の心臓部である「サムネイルコピー」および「タイトル」を策定・提案する際、**例外なく常にサブエージェントによるアルゴリズム＆心理学監査を実行する**ための運用プロトコルである。

---

## 1. 監査の絶対KPI体系 ＆ 客観的確率モデル

「確信度」は単なる企画の品質スコアではなく、チャンネルの過去実測データ（`data/youtube_analytics_history.csv`）に基づいた**客観的な達成確率（確率論）**として厳格に算定しなければならない。

$$\text{優先順位: } \mathbf{① \text{ インプレッション 10万回以上}} > \mathbf{② \text{ CTR 5.0\% 以上}} > \mathbf{③ \text{ 連続視聴時間（AVD） 30分以上}}$$

### 📊 規模別・多段階の達成確率モデル（標準出力フォーマット）
1. **【ベースライン到達確率（1万インプ規模）】**: 手堅く到達できる確率（通常 80%〜90%台）
2. **【過去最高更新確率（3万〜5万インプ規模）】**: チャンネル記録（2.7万回）を更新しブラウジングに乗る確率（通常 40%〜60%）
3. **【メガヒット到達確率（10万インプ規模）】**: ホーム画面で大衆へ無差別配給される確率（通常 20%〜35%）
4. **【3大KPI 完全同時達成確率】**: 「10万インプ」×「CTR 5.0%維持」×「AVD 30分」が同一動画で同時成立する確率（通常 15%〜25%）
   * ※YouTubeの数理構造上、インプレッションが10万回規模に巨大化すると大衆流入によりCTRは必然的に2.5%〜3.5%へ希釈されるため、10万インプ到達下でのCTR 5%維持は極限領域となる。

## 2. 常時監査の実行ワークフロー（台本・タイトル・サムネの絶対義務化）

**【絶対原則】台本（プロジェクトドキュメント）、動画タイトル、サムネイルの新規作成・修正・提案を行う際、専門サブエージェント（Senior YouTube Growth Strategist）による事前監査の省略は「重大プロセス違反」として永久に禁止する。メインエージェント単独での直接出力は一切認められない。**

1. **メインエージェントが初案（タイトル・サムネ・台本構造）を策定**:
   * 最低3パターン（初期本命案、差し替え案①、差し替え案②）を考案。
2. **専門サブエージェント（`Senior YouTube Growth Strategist`）を invoke_subagent で必ず召集・事前監査を実行**:
   * **台本全体の完全固定テンプレート（v4.2）構造監査**:
     - `private_reports/pomosta_script_generation_rule_v4.2.md` および `01_Template_Project_v4.2.md` との100%照合。
     - **【画像プロンプト構図差し替えマーク確認（絶対厳守）】**: FocusおよびBreakの画像プロンプト本文（textブロック）において、カメラ構図・視点（POV）の指定部分が `**...**` で囲まれ、下部の「💡代替カメラ構図タグ」との差し替え対象箇所が明示されているか？
     - 概要欄の全セクション（冒頭フック、情景、姉妹動画リンク、🧠こだわり、⏱️タイムスタンプ、▶️公式再生リストURL、⚙️制作について、⚠️ご注意、ハッシュタグ）の完全網羅。
     - **【読書需要の完全網羅チェック（絶対厳守）】**: 日本語概要欄（本文用途、読書タイムCTA、🧠音響こだわりでの読書言及、`#読書用bgm`）、英語概要欄（Title・DescriptionでのReading言及、`#readingmusic`）、メタタグ（`読書用bgm`, `reading music` 等）に読書情報が100%配備されているか？
     - メタタグ（上限500文字中470〜495文字最適化）、`> [!note]- v1: オトノバ君` コールアウト、画像代替構図タグ2案の欠落チェック。
   * **17大敗因チェックリスト（`low_ctr_failed_cases_database.md`）の100%照合**:
     - 【最重要チェック1】タイトル先頭15文字の動詞規約（完了成果型・最高峰状態型のみ。「進む」「始める」「続く」の完全禁止）。
     - 【最重要チェック2】サムネとタイトルの文言被り（同語反復・部分一致）の完全ゼロ確認（二重トラップの完全性）。
     - 【最重要チェック3】サムネ末尾着地ワードの連続被り防止（「手が動く」「片付く」等の連続は禁止。**ただしユーザーが最も求めるコア欲求である『集中』のみ即却下ルールを完全免除**。フックが別アングルに変化していれば連続採用を認める）。
     - 【最重要チェック4】過去の低CTR失敗事例（CASE-01「驚くほど集中できる」等の陳腐フレーズ）の完全排除。
     - 【最重要チェック5】大衆直感性テスト（比喩・ポエム『深く潜る』等の完全排除、小中学生でも0.05秒で直感理解できる直球語のみ採用）。
   * **実績データCSVの参照**: `data/youtube_analytics_history.csv` を直接読み込み、直近4〜7本の動画タイトル・サムネの重複・クールダウンを完全検証。
   * **概要欄（Description）日本語・英語品質・平易化監査**:
     - 専門用語・学術用語の完全排除（「言語野」「ワーキングメモリ」「phonological loop」等を「読む・書く・考える力」「思考スペース」「mental distraction」に平易化）。
   * **多段階客観的確信度モデルの厳密算定**:
     - 1万インプ、3〜5万インプ、10万インプ、3大KPI完全同時達成率を客観算定。
3. **サブエージェントの「完全合格（Pass）」判定を受けてから台本ファイル書き込み＆ユーザー提示**:
   * サブエージェントの指摘事項を100%反映し、全チェックリストをパスした完全版のみをユーザーへ納品する。

## 3. タイトル＆概要欄作成の絶対レギュレーション

今後のすべての動画タイトルおよび概要欄において、以下の執筆基準を固定ルールとして適用する。

### 🏷️ タイトル制作の絶対方針（インプレッション最大化 ＆ 小中学生直感語の義務化）
1. **文学的・カッコ良い表現の完全禁止（出戻りゼロ規定）**:
   * 小説的な情景描写や気取った比喩表現（例:「雨の摩天楼を見下ろす書斎で」「深く潜る」「静寂に沈む」「思考が澄み渡る」「知性を研ぎ澄ます」等）は**タイトルにおいて1文字も使用を禁止**する。
   * 情景・世界観は「サムネイル画像」が100%伝えるため、タイトルで言葉を重ねることは認知負荷（ブレーキ）にしかならない。
2. **小中学生でも一瞬で理解でき惹かれる言葉の義務化**:
   * タイトルの役割は**「SEO検索キーワードの網羅」＋「直感的な実利（ベネフィット）」に完全特化**すること。
   * 「雨の日に」「勉強がはかどる」「作業が一気に終わる」「頭がスッキリする」「自然と集中できる」等、10代の学生から大人まで全員が日常会話で使う平易で強い欲望ワードのみで構成する。

### 📝 概要欄（Description）の平易化マッピング
1. **専門用語の平易化マッピング**:
   - `言語野 / ワーキングメモリ` ➔ `読む・書く・考える力` / `思考スペース` / `脳のエネルギー`
   - `認知負荷 / 認知的フリクション` ➔ `思考の邪魔` / `余計なストレス`
   - `phonological loop (英)` ➔ `mental distraction` / `free your mind`
2. **自然な動詞・助詞の接続（状況想起の保証）**:
   - 単語を強引に圧縮したコピー調（体言止めの連続）を避け、視聴者が「自分がその空間で作業している姿」をスムーズに想像できる丁寧で流暢な日本語にする。
   - 冒頭注記の標準形:
     `※本動画はピアノ・楽器を一切使用しない【完全自然音（音楽なし）】仕様です。周囲の雑音をゼロにして静寂の中で集中したい時にご活用ください☕`
3. **【読書（Reading）の必須組み込み規約（絶対厳守）】**:
   - 読書層は離脱が極めて少なく長大AVDをもたらすため、日本語概要欄の用途に「読書」、CTAに「読書の時間」、音響こだわりに「読書・テキスト読解の邪魔ゼロ」、ハッシュタグに `#読書用bgm` を必ず含める。
   - 英語側でもTitleに `Reading`、Descriptionに `reading flow`、ハッシュタグに `#readingmusic` を必ず配備する。
4. **完全日英分離**:
   - 日本語ブロックと英語ブロックを完全に分離し、それぞれの言語文化において最も自然で品格のある文体（Quiet Luxury）を維持する。
