# 📊 YouTubeアナリティクス常時監査プロトコル（Agent自動適用ルール）

AIエージェントは、ユーザーからYouTubeアナリティクス（Studio画面、スクリーンショット、数値）の共有を受けた際、**必ず以下の5大原則に照合して分析・診断を行わなければならない**。

---

## 1. 🚨 必須チェック5原則（過大・過小評価の完全防止）

1. **配給フェーズの峻別（シード期 vs 大衆拡大期）**:
   * **インプ1,000回未満（数十〜数百回 / 公開0〜24h）**:
     * 「チャンネル登録者・コア視聴者向けシード配信」と判定する。
     * **基準値: CTR 5.0%〜10.0%+ が適正水準**。
     * 4.0%前後は「登録者向けとしては普通〜やや低め（スルーあり）」と判定し、大衆向け基準（2〜3%）と混同して「4%だから高CTR！」と過大評価してはならない。
   * **インプ数千〜数万回以上（公開24h〜数日）**:
     * 「ホーム画面おすすめ（Browse 70%+）による大衆拡大期」と判定する。
     * **基準値: CTR 2.0%〜3.5% が健全・ヒット水準**（3.0%超で大ヒット候補）。
     * 分母爆大に伴うCTR低下（2.0〜2.5%）は正常なアルゴリズム現象と評価する。

2. **コンテンツ属性と登録者プールの「嗜好ミスマッチ」判定**:
   * ピアノ版で集まった登録者プールに「音楽なし（自然音単体）」を配信した場合、登録者の60〜70%を占めるピアノ好きがスルーするため、初動シードCTRが5%を割り込みやすい構造的宿命を必ず指摘すること。
   * 背景同一流用の場合は「バナーブラインドネス（既視感スルー）」の介在を検証すること。

3. **ユニーク視聴者数（Unique Viewers）のタイムラグ原則**:
   * YouTube Studioの「ユニーク視聴者数」はリアルタイムではなく**24〜48時間の確定遅延**がある。
   * リアルタイムの視聴回数（Views）と単純に割り算して「1人あたり〇回リピート！」と早合点して過大評価することを厳禁とする。

4. **AVD（平均視聴時間）の文脈判定**:
   * シード期（視聴数十回）の高AVD（40〜50分超）は、「熱心な少数のガチ勢が回した結果」であり、大衆受けが確定したわけではないと冷静に解釈する。
   * 大衆拡大期（視聴1,000回超）のAVD 25分超は、「大衆がポモドーロツールとして実際に完走している」本物の怪物シグナルと判定する。

5. **トラフィックソース比率判定**:
   * Browse 70%以上：おすすめアルゴリズム乗波。
   * Suggested 30%以上：乗り換えハードルの高い戦場。
   * Search 15%以上：自然音・ニッチ需要の自力獲得。

## 2. 📋 回答構成フォーマット
診断時は必ず以下の4ステップで回答する：
1. **配給フェーズ判定**（シード期か大衆期か、露出対象は誰か）
2. **指標診断**（各フェーズの適正基準値との客観的照合、ユニーク数遅延の注記）
3. **トラフィック＆背景分析**（戦場分析、登録者嗜好との相性、既視感の有無）
4. **今後のアルゴリズム分岐点とアクション**（スケール条件、差し替え要否）
